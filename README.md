# Games

KiritoShikahara が作ったゲームの配布用ページです。ソースコードは置いていません。

## 遊ぶ手順

1. 下の一覧からゲームの「ダウンロード」を開き、zip を保存する
2. zip を右クリック →「すべて展開」
3. 展開したフォルダーの中の exe をダブルクリック

「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください。署名の無い個人制作のゲームで出る表示です。
