# AETHER EDGE

剣と魔導銃で戦う 2D 横スクロールアクション。絵も音もすべてプログラムで生成しています。

- 序章（チュートリアル）＋全7章、計43ステージ
- 故45種、章ごとに専用ギミックを持つボス
- 魔導銃6属性、パリィとジャスト回避

## ダウンロード

展開した `AetherEdge` フォルダーの `AetherEdge.exe` を起動します。フォルダーごと使ってください（exe だけを移すと動きません）。

## 動作環境

- Windows 10 / 11（64bit）
- ゲームパッド推奨（キーボード＋マウスでも遊べます）

## 操作

| 行動 | ゲームパッド | キーボード / マウス |
|---|---|---|
| 移動 | 左スティック | A D W S / 矢印 |
| ジャンプ（長押しで高く） | A | Space / Z |
| 剣（5段連撃） | X | 左クリック / J / X |
| 射撃 | Y または右スティック（向けた方向へ） | 右クリック / K / C |
| 属性切替 | LB / RB | ホイール / Q E / 1 2 |
| ダッシュ | B | Left Shift |
| パリィ | RT | F / R |
| 技（習得後） | LT | L / V / 中クリック |
| 一時停止 | Start | Esc / P |
